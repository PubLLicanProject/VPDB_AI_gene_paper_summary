## Environment / conventions
- Branch **`JT`** (main is the old pre-OpenRouter pipeline). All PD generation = **Sonnet 4.5 via
  OpenRouter**. Do NOT swap to Sonnet 5 (over-refuses this content).
- Run Python via the repo venv: **`venv/Scripts/python.exe`** (bare `python`/`py` may be the wrong
  interpreter and miss `xlrd`/`olefile`/etc.). Set `PYTHONUTF8=1` on Windows.
- Long jobs: launch with shell `&` (harness reaps tracked background jobs). Kill by PID; **never**
  `taskkill //IM python.exe` (it corrupted cache JSONs once).
- Pipeline API key is on a **separate account** — not gated by the user's Claude Code spend limit.

## What this workstream does
Generate PDs for gene-paper pairs referenced by VEuPathDB user comments.
`STEP_4_Large_scale_user_comment_evaluation.py` is **judge-only** (runs `evaluateUserCommentAlignment`
over PRE-EXISTING `getGeneSummary/generatePDs/verifyPDs` in `out/user_comment_evaluation/{pmid}.json`);
**STEP_3 generates** those stages.

## Scripts (all committed on JT)
- `preprocess_user_comments.py` — mention pre-check mirroring STEP_3's gate. Modes:
  - default (comments TSV, primary `Gene ID`), `--include-related` (also explode `Related Stable IDs`),
    `--priority PATH` (curated priority TSV `gene_id/pmid/database`; normalizes PMIDs: strip `.0`, drop
    DOI/PMCID). Gene-aware resume. Output `curated_data/{tag}_precheck.csv` + summary.
- `run_user_comment_pd_batch.py [precheck.csv] [workers] [--supplements]` — STEP_3 batch (summary→
  generatePDs→verifyPDs, **no judge**) into `out/user_comment_evaluation/`. **Always pass `--supplements`**
  for these sets (they are dominated by supplement-unlock pairs; without it those genes refuse/produce nothing).
- `collect_guardrail_examples.py` — compiles Sonnet-4.5 guardrail-blocked stages across ALL caches →
  `out/guardrail_examples/`. For sharing with collaborators.

## Gotchas learned this session
- Build comment pairs from BOTH `Gene ID` AND `Related Stable IDs` (a comment lists ~100 related genes);
  primary-only under-scopes badly. The TSV's multi-line quoted `Content` parses fine — not a bug.
- **NCBI BioC (`pmcoa.cgi`) is flaky** — had a multi-hour "no healthy upstream" 503 outage + flapping.
  Transient, not us (confirmed via different-IP WebFetch). **Supplements come from Europe PMC** (up
  independently). Before launching, poll for stable recovery (≥3 consecutive healthy 200s). Batch fetch
  is hardened (retries) and resumable, so transient fails cost nothing and are retried on re-run.
- Guardrail refusals concentrate on specific papers/databases (FungiDB); expected residual of the model.
